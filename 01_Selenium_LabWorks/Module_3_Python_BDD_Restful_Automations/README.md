# Module 3 - Python BDD & RESTful Automation

## Overview

This module demonstrates Selenium automation using Python and Behavior Driven Development (BDD) with Behave.

The project automates the Rahul Shetty Academy Automation Practice page and validates multiple web elements and browser interactions.

## Technologies Used

- Python
- Selenium WebDriver
- Behave
- Pytest
- Requests
- Chrome WebDriver
- Gherkin
